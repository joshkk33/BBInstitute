# BBInstitute

Open-source research tools from the Bear Branch Institute, the research arm of
[Bear Branch Sanctuary, Inc.](https://bearbranch.org), a 501(c)(3) nonprofit.

| Tool | What it does |
|---|---|
| [`sabine-occupancy/`](sabine-occupancy/) | Adds occupants to a measured empty-room reverberation time or impulse response. It is a single Python file that needs only numpy. Presented at the 191st ASA Meeting, Baltimore, December 2026. Includes [reverb presets](sabine-occupancy/rooms/) of five ancient rooms, empty and full. |

Each tool is self-contained. Copy its folder, or just its one file, into your own project.
