# BBInstitute

Open-source research tools from Bear Branch Sanctuary, Inc., a 501(c)(3) nonprofit.

| Tool | What it does |
|---|---|
| [`sabine-occupancy/`](sabine-occupancy/) | Adds occupants to a measured empty-room reverberation time or impulse response. It is a single Python file that needs only numpy. Presented at the 191st ASA Meeting, Baltimore, December 2026. |

Each tool is self-contained. Copy its folder, or just its one file, into your own project.
